# قسم الموديلات وربطه بحجز المواد

قسم جديد مستقل للموديلات الخاصة بالمحل، كل موديل بمواده المستخدمة. عند اختيار رقم الموديل في الطلب الجديد تُعرَّف مواده تلقائيًا وتُحجز كما هي. الموديل الجديد يختار له القماش والدانتيل والتطريز يدويًا من المخزون ويُحجز، دون حفظه في قائمة الموديلات.

## قسم «الموديلات» (عنصر رئيسي في القائمة)

قائمة الموديلات:
- بحث برقم الموديل أو الاسم، وفلتر بنوع القطعة، وفلتر المفعّل/المعطّل.
- كل صف: صورة مصغّرة، رقم الموديل، الاسم، نوع القطعة، السعر التقديري، عدد المواد.
- زر «موديل جديد» يفتح نموذج إضافة: رقم الموديل (فريد)، الاسم، نوع القطعة، السعر التقديري، وصف وملاحظات تصنيع، صور.

صفحة الموديل:
- بطاقة البيانات (قابلة للتعديل) + معرض الصور مع رفع/حذف صورة.
- بطاقة «المواد المستخدمة»: إضافة مادة من المخزون بكمية، تعديل الكمية، حذف السطر. تظهر وحدة القياس والمتاح في الفرع الحالي بجانب كل مادة.
- تعطيل الموديل بدل حذفه (لا يظهر للاختيار في الطلبات الجديدة لكن الطلبات القديمة تبقى).

## الطلب الجديد — بطاقة الموديل

- «موديل موجود»: حقل رقم الموديل يصير قائمة اختيار من الموديلات المفعّلة (بحث بالرقم/الاسم). بعد الاختيار تظهر قائمة مواد الموديل بكمياتها **للعرض فقط** (غير قابلة للتعديل) مع تنبيه أحمر لأي مادة كمية المتاح فيها أقل من المطلوب.
- «موديل جديد»: تُختار المواد يدويًا مقسومة إلى ثلاث مجموعات — القماش، الدانتيل، التطريز والخرز — بالإضافة إلى بقية المواد، بكمية لكل مادة. (يحل محل قائمة «موديل التطريز» النصية الحالية والمطابقة التقريبية بالأسماء.)
- عند الحفظ: تُحجز مواد الموديل المختار (أو المواد المختارة يدويًا) على الطلب عبر الحجز الحالي نفسه. المواد المحجوزة تظهر في صفحة الطلب كما اليوم.
- الموديل الجديد لا يُحفظ في قائمة الموديلات.

## صفحة الطلب

سطر «الموديل» يعرض رقم الموديل واسمه ورابطًا لصفحة الموديل عند وجوده.

## تفاصيل تقنية

هجرة `0016_models_catalog.sql`:
- `models`: id, code (unique), name, item_type_id → item_types, est_price numeric default 0, description, notes, is_active bool default true, created_at, created_by.
- `model_images`: id, model_id → models on delete cascade, storage_path, position, created_at. الصور في bucket `inventory` تحت `models/<model_id>/`.
- `model_materials`: id, model_id → models on delete cascade, material_id → materials, qty numeric not null check > 0, unique(model_id, material_id).
- `orders.model_id uuid references models(id)` مع الحفاظ على `model_no` كنص للطلبات القديمة.
- GRANT SELECT/INSERT/UPDATE/DELETE للـ authenticated و ALL لـ service_role على الجداول الثلاثة، ثم ENABLE RLS، وسياسات على نمط `item_types`: قراءة للفريق (`private.is_staff`)، كتابة للمدير/المشرف (`private.has_role`/`private.can('models.manage')`).

الكود:
- `src/lib/models-data.ts`: `useModels`, `useModel`, `useSaveModel`, `useModelMaterials`, `useSetModelMaterial`, `useRemoveModelMaterial`, `useModelImages`, `useUploadModelImage`, `useDeleteModelImage`.
- مسارات جديدة: `src/routes/_authenticated/models.index.tsx` و`models.$modelId.tsx`، ورابط «الموديلات» في `AppShell.tsx` بأيقونة `Shirt` (للفريق، والتعديل للمدير/المشرف).
- `orders.new.tsx`: بطاقة «الموديل» تستخدم `useModels` للاختيار و`useModelMaterials` لعرض المواد؛ حالة `picked` تُملأ من مواد الموديل ولا تُعرض للتعديل عند اختيار موديل موجود؛ عند «موديل جديد» تُعرض قوائم المواد مجمّعة بالتصنيف (`material_categories`) مع خانات كمية. الحفظ يُرسل `model_id` و`model_no` معًا، ويُلغى الـ `useEffect` الحالي للمطابقة بالاسم.
- `orders.$orderId.tsx`: صف الموديل يقرأ `model_id` ويعرض رابطًا.
- لكل مسار جديد `head()` بعنوان ووصف خاصين.
