# ربط الواتساب بتنبيه العميلة بالمواعيد

الهدف: زر واتساب داخل النظام يفتح محادثة العميلة برسالة جاهزة معبّأة ببيانات طلبها، مع صفحة لتعديل نصوص الرسائل.

## ما ستحصل عليه

- زر «واتساب» في صفحة الطلب، وفي قوائم الطلبات، وفي المتأخرات، وفي فستان الإيجار.
- عند الضغط تُفتح قائمة قصيرة تختار منها نوع الرسالة (تأكيد الحجز، تذكير البروفة الأولى، تذكير البروفة الثانية، الجاهزية للتسليم، تذكير مبلغ متبقٍ، تذكير إرجاع فستان الإيجار).
- تُفتح محادثة الواتساب مع رقم العميلة والنص جاهزًا؛ الإرسال يبقى بضغطة منك (بدون أي تكلفة أو موافقات).
- صفحة «رسائل الواتساب» لتعديل نص كل رسالة، مع معاينة فورية وحقول جاهزة للإدراج مثل اسم العميلة ورقم الطلب وتاريخ البروفة والمبلغ المتبقي.
- تعديل النصوص للمدير والمشرف فقط، والاستخدام متاح لمن يرى الطلب.
- تسجيل كل إرسال في سجل النشاط حتى تعرف من أرسل ومتى.

## قاعدة البيانات

جدول جديد `whatsapp_templates`:
- `key` (نوع الرسالة، فريد)، `label`، `body`، `is_active`، `position`، `updated_at`.
- تفعيل RLS: قراءة للموظفين المسجّلين، تعديل/إضافة للمدير والمشرف عبر `private.has_role`.
- منح `GRANT` للـ `authenticated` و`service_role` في نفس الـ migration.
- إدراج النصوص العربية الافتراضية للرسائل الستة داخل الـ migration نفسه.

## تفاصيل فنية

- `src/lib/whatsapp.ts`: تنظيف رقم الجوال إلى صيغة دولية (افتراضي مفتاح السعودية 966 عند رقم محلي يبدأ بـ 0 أو 5)، دالة استبدال المتغيّرات في النص، وبناء رابط `https://wa.me/<phone>?text=<encoded>`.
- `src/lib/whatsapp-data.ts`: hooks للقراءة والتعديل عبر عميل Supabase في المتصفح مثل بقية `*-data.ts`.
- `src/components/WhatsAppButton.tsx`: زر + قائمة القوالب، يستقبل الطلب أو سجل الإيجار، يبني الرابط ويفتحه في تبويب جديد، ويكتب سطرًا في `activity_log`.
- إضافته إلى `orders.$orderId.tsx`، `orders.index.tsx`، `late.tsx`، `rentals.$dressId.tsx`.
- مسار جديد `src/routes/_authenticated/whatsapp.tsx` لتحرير القوالب، مع رابط في `AppShell` (للمدير والمشرف)، و`head()` خاص بالصفحة.
- عند غياب رقم الجوال يظهر الزر معطّلًا برسالة «لا يوجد رقم جوال».

## غير مشمول الآن

- الإرسال التلقائي بدون تدخل (يحتاج WhatsApp Business API لاحقًا).
- استقبال ردود العميلة داخل النظام.

لاحقًا إذا أردت الإرسال التلقائي، نبني فوق نفس القوالب دون إعادة عمل.
