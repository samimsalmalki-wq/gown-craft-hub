# تطوير النظام: الموظفون ومراحل التصنيع

نبني هذه المرحلة **فوق** النظام الحالي: لا حذف لأي شاشة أو بيانات موجودة. الطلبات الستة التجريبية والمراحل الحالية تبقى كما هي، وتُرقّى تلقائيًا للهيكل الجديد.

## 1. توسيع قاعدة البيانات (إضافة فقط)

- **الأقسام**: جدول أقسام (الإدارة، خدمة العملاء، القياسات، التصميم، القص، الخياطة، التطريز، التشطيب، التعديلات، الجودة، التسليم).
- **الموظفون**: توسيع ملف الموظف الحالي بصورة، القسم، الحالة (نشط/غير نشط)، والمراحل المسموح له بتنفيذها.
- **الأدوار**: إضافة «مشرف» و«خدمة عملاء» إلى الأدوار الحالية (مدير، موظف)، مع صلاحيات قابلة للتعديل من المدير.
- **قالب المراحل**: جدول مراحل قابل للتعديل من المدير (إضافة/تعديل/ترتيب/تعطيل) يشمل الـ16 مرحلة المطلوبة — تُضاف «اعتماد التصميم» و«التطريز» و«التعديلات النهائية» إلى المراحل الحالية.
- **مراحل الطلب**: إضافة حالات جديدة (مسندة، تحتاج مراجعة، متأخرة) بجانب الحالات الحالية، مع تاريخ الإسناد، الموعد المتوقع، الأولوية، مدة التنفيذ، سبب التأخير، وبيانات المراجعة (معتمد/مرفوض + السبب + المراجع + التوقيت).
- **التعديلات (Alterations)**: جدول مستقل مرتبط برقم الطلب: رقم التعديل، الوصف، الملاحظات، الموظف المسؤول، تاريخ الطلب، تاريخ التنفيذ، الحالة، والصور. لا يُحذف ولا يُستبدل تعديل قديم.
- **سجل الحركات (Activity Log)**: جدول للقراءة فقط للمستخدمين، يُكتب تلقائيًا عبر مشغّلات قاعدة البيانات عند: إنشاء طلب، تغيير مرحلة، إسناد، بدء/إيقاف/إنهاء، اعتماد/رفض، إضافة تعديل، إضافة صورة، تغيير موعد التسليم أو حالة الدفع.
- **التنبيهات**: جدول تنبيهات لكل مستخدم (مهمة جديدة، رفض، اعتماد، اقتراب التسليم، تأخير) مع حالة القراءة.
- كل الجداول محمية بقواعد وصول: المدير والمشرف يريان الكل، الموظف يرى ما أُسند إليه، خدمة العملاء تقرأ بيانات العميلة والمواعيد فقط.

## 2. الشاشات الجديدة والمحدّثة

| الشاشة | المحتوى |
| --- | --- |
| **الموظفون** (تطوير الحالية) | قائمة بالصورة، الاسم، الجوال، المسمى، القسم، الحالة، المراحل المسموحة، والصلاحيات القابلة للتعديل |
| **ملف الموظف** (جديد) | البيانات، المراحل المسموحة، المهام الحالية، المنجزة، المتأخرة، عدد المهام المفتوحة، وسجل الإنجاز |
| **مهامي** (جديد) | مهام الموظف فقط مع رقم الطلب، العميلة، صورة الفستان، المرحلة، الأولوية، الاستحقاق، الحالة، وترتيب حسب الأهم/الأقرب/الأقدم/الأولوية |
| **لوحة الإنتاج** (تطوير شاشة المراحل) | لوحة كانبان بأعمدة المراحل، بطاقات تعرض الطلب والعميلة والصورة والمسؤول والتسليم والأولوية والأيام المتبقية، ونقل المرحلة بلمسة واحدة مع تسجيل الحركة |
| **المتأخرات** (جديد) | الطلبات المتجاوزة موعد المرحلة أو التسليم، مع المسؤول وأيام التأخير وسبب التأخير |
| **تقرير أداء الموظفين** (جديد، للمدير) | المنجز/الحالي/المتأخر، متوسط مدة التنفيذ، إعادة العمل، المرفوض، المعتمد — لليوم/الأسبوع/الشهر/فترة مخصصة |
| **تفاصيل الطلب** (تطوير) | خط زمني واضح للمراحل مع تمييز قوي للمرحلة الحالية، وفتح تفاصيل أي مرحلة |
| **تفاصيل المرحلة** (جديد) | الحالة، المسؤول، أوقات الإسناد/البدء/الانتهاء، الموعد المتوقع، المدة، الأولوية، الملاحظات، الصور والملفات، سبب التأخير، وأزرار بدء/إنهاء/إسناد ومراجعة (اعتماد ✓ / رفض ✕ / إعادة ↻) |
| **التعديلات والبروفات** | داخل شاشة الطلب: قائمة تعديلات مرقّمة تراكمية بصور وملاحظات وحالة |
| **التنبيهات** | جرس في الشريط العلوي مع قائمة التنبيهات غير المقروءة |

## 3. سير العمل

1. المدير/المشرف يُسند المرحلة لموظف مع موعد متوقع وأولوية → تنبيه للموظف وظهور المهمة في «مهامي».
2. الموظف: «بدء العمل» يسجّل الوقت → «إنهاء العمل» يسجّل الوقت والمدة.
3. إذا كانت المرحلة تحتاج اعتمادًا: تنتقل إلى «بانتظار المراجعة» بدل «مكتملة».
4. المشرف يعتمد (تتقدّم المرحلة التالية تلقائيًا) أو يرفض بسبب مكتوب (تعود للموظف مع تنبيه).
5. كل خطوة تُسجّل في سجل الحركات ولا تُمحى.

## 4. الترتيب التنفيذي

1. توسيع قاعدة البيانات + ترقية بيانات الطلبات الحالية للمراحل الجديدة.
2. الأدوار والصلاحيات + شاشة الموظفون وملف الموظف.
3. تفاصيل المرحلة + الإسناد + بدء/إنهاء + المراجعة + سجل الحركات.
4. مهامي + لوحة الإنتاج + التنبيهات.
5. المتأخرات + تقرير الأداء + التعديلات.
6. فحص عملي لكل نقطة من قائمة التحقق في طلبك.

## افتراضات

- إنشاء الموظف يتم بإنشاء حساب للموظف بنفس طريقة الدخول الحالية (بريد وكلمة مرور)، والمدير يستكمل بياناته (القسم، الصورة، المراحل).
- صورة الفستان في البطاقات تُؤخذ من أول صورة مرفوعة للطلب.
- التصميم يبقى «دفتر الأتيليه» العربي RTL الحالي، بدون إعادة تصميم للشاشات القائمة.
